A transparent token-launch radar: 198 pre-token protocols valued from the sealed snapshot's own figures — TVL, category peer market-cap/TVL multiples shrunk toward the global median, 7-day TVL growth, and time without a token. Every row states an implied launch value, a sensitivity band derived from peer dispersion, and a concrete 6-step farm plan; the generated offline dashboard (sortable board, per-protocol detail showing the full valuation equation, category filter) ships next to `board.json` and `dossier.json`.

## Run it

```sh
node main.ts --input snapshot.json --output output --screenshots screenshots
```
